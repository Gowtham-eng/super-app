Google Workspace OAuth for RefexOne

Give this page to your Google Workspace / Google Cloud admin.

Important: RefexOne does not store Google passwords. Users sign in with Google; their RefexOne account must already exist (HR sync or admin-created).

1. Google Cloud Console

  1. Open Google Cloud Console.
  2. Create or select a project for RefexOne.
  3. Go to APIs & Services → OAuth consent screen → Internal (Workspace) or External.
  4. Go to Credentials → Create credentials → OAuth client ID → Web application.

2. Redirect URI (required)

Add this authorized redirect URI exactly:

https://refexone.com/api/auth/google/callback

For local dev:

http://localhost:8000/api/auth/google/callback

3. Scopes

RefexOne uses OpenID Connect scopes only:

  • openid
  • profile
  • email

4. Return to RefexOne admin

In RefexOne → Google Login (/settings/google), add:

  • Label (e.g. Refex Google Workspace)
  • OAuth Client ID
  • OAuth Client Secret
  • Email domains: refex.co.in
  • Hosted domain (optional): refex.co.in

5. Test

  1. Ensure the user exists in RefexOne with the same Google email.
  2. Open RefexOne login → Sign in with Google.
